# Congreso Filosófico — IE José Celestino Mutis

Sitio web oficial del Congreso Filosófico de la **Institución Educativa José Celestino Mutis**, colegio ubicado en Bucaramanga, Santander, Colombia.

Desarrollado por estudiantes de la institución como proyecto académico para digitalizar y publicar las ponencias del congreso anual.

## ¿De qué va?

El Congreso Filosófico es un espacio académico donde estudiantes y docentes presentan ponencias sobre temas de filosofía contemporánea. Este repositorio contiene el código fuente del sitio web que sirve como archivo digital de esas ponencias.

La edición XII abordó el debate entre la capacidad racional humana y el avance de la inteligencia artificial, desde una mirada filosófica y ética.
