# Congreso Filosófico — IE José Celestino Mutis

Sitio web oficial del Congreso Filosófico de la **Institución Educativa José Celestino Mutis**, colegio ubicado en Bucaramanga, Santander, Colombia.

Un proyecto de la comunidad educativa para la comunidad educativa, y para todo el mundo. Nace con la idea de preservar un espacio filosófico libre, donde cada edición suma nuevas corrientes de pensamiento que seguirán llegando.

## ¿De qué va?

El Congreso Filosófico es un espacio académico donde estudiantes y docentes presentan ponencias sobre temas de filosofía contemporánea. Este repositorio contiene el código fuente del sitio web que sirve como archivo digital de esas ponencias, con la intención de preservar y difundir el pensamiento filosófico escolar más allá del aula.
